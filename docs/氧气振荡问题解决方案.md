# 氧气振荡问题解决方案

## 问题描述

在启用点火核的模拟中，右腔的氧气浓度（Y_O2）出现不合理的振荡，而不是保持稳定的初始值 0.23。

## 根本原因分析

### 原因1：右腔组分强制方法不当

在每个时间步后，代码强制右腔组分保持初始值以防止燃烧产物进入右腔：

```python
# 旧方法（有问题）
delta_H2 = self.U[i, 3] - Y_H2_init * rho
delta_O2 = self.U[i, 4] - Y_O2_init * rho
delta_H2O = self.U[i, 6] - Y_H2O_init * rho

# 强制组分
self.U[i, 3] = Y_H2_init * rho
self.U[i, 4] = Y_O2_init * rho
self.U[i, 6] = Y_H2O_init * rho

# 所有偏差都分配给N2
self.U[i, 5] += delta_H2 + delta_O2 + delta_H2O
```

**问题**：所有偏差都分配给N2，导致N2的质量分数剧烈变化（例如从0.77变到0.85）

### 原因2：归一化阈值过大

在 `primitive_variables()` 中的归一化逻辑：

```python
# 旧方法（阈值太大）
if deviation > 0.01:  # 1%的阈值
    Y_H2 /= Y_sum
    Y_O2 /= Y_sum
    Y_N2 /= Y_sum
    Y_H2O /= Y_sum
```

**问题**：
- N2的剧烈变化导致 Y_sum 偏离1.0
- 下一次调用时，由于偏离超过1%，所有组分被重新归一化
- 这导致氧气出现振荡

## 解决方案

### 修复1：改进右腔组分强制方法

```python
# 新方法（改进）
# 计算目标组分质量
rho_Y_H2_target = Y_H2_init * rho
rho_Y_O2_target = Y_O2_init * rho
rho_Y_N2_target = Y_N2_init * rho
rho_Y_H2O_target = Y_H2O_init * rho

# 计算需要调整的总质量
delta_total = (rho_Y_H2_curr - rho_Y_H2_target) + \
              (rho_Y_O2_curr - rho_Y_O2_target) + \
              (rho_Y_H2O_curr - rho_Y_H2O_target)

# 强制组分
self.U[i, 3] = rho_Y_H2_target
self.U[i, 4] = rho_Y_O2_target
self.U[i, 6] = rho_Y_H2O_target

# 平衡分配给N2
self.U[i, 5] = rho_Y_N2_target + delta_total
```

**改进**：N2从初始值平滑调整，而不是累积所有偏差

### 修复2：降低归一化阈值

```python
# 新方法（更严格的阈值）
if deviation > 0.001:  # 0.1%的阈值
    Y_H2 /= Y_sum
    Y_O2 /= Y_sum
    Y_N2 /= Y_sum
    Y_H2O /= Y_sum
```

**改进**：只在偏离超过0.1%时才归一化，减少不必要的重新归一化

## 效果验证

修复后的预期结果：

- ✅ 右腔Y_O2保持稳定在 0.23 ± 0.001
- ✅ 右腔Y_H2O保持为 0.00e+00
- ✅ 右腔无燃烧
- ✅ 质量守恒得到保证
