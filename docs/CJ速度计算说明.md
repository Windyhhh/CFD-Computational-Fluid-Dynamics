# CJ速度计算说明

## 什么是CJ速度？

CJ (Chapman-Jouguet) 速度是爆轰波的传播速度，是爆轰理论中的关键参数。

## 当前输出说明

根据你的描述，代码输出包括：

### 1. CJ Speed（爆轰波传播速度）
- **定义**：爆轰波前（最高压力点）的传播速度
- **计算方法**：追踪最高压力点的位置随时间的变化
- **公式**：`CJ_speed = Δx / Δt`
  - Δx：两个时刻最高压力点的位置差
  - Δt：时间差

### 2. CJ Pressure（爆轰波后压力）
- **定义**：爆轰波后（左腔）的最高压力
- **当前值**：13.713 MPa (135.3 atm)
- **位置**：x = 22.92 m

## CJ速度的正确计算方法

### 方法1：追踪压力波前
```python
# 在不同时刻找到最高压力点的位置
t1 = 0.002s, x1 = 10.0m, p1 = 13.5MPa
t2 = 0.004s, x2 = 15.0m, p2 = 13.7MPa

# 计算传播速度
CJ_speed = (x2 - x1) / (t2 - t1)
         = (15.0 - 10.0) / (0.004 - 0.002)
         = 2500 m/s
```

### 方法2：使用理论公式
对于理想气体，CJ速度可以通过以下公式估算：
```
D_CJ = a₁ * sqrt(1 + (γ₁+1)/(2γ₁) * (p₂/p₁ - 1))
```
其中：
- a₁：初始声速
- γ₁：初始比热比
- p₂/p₁：压力比

### 方法3：从数值结果提取
从时空图（P-x-t diagram）中提取爆轰波前的斜率。
