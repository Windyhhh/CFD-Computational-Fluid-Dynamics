## 修复方案总结

**位置：** `shock_tube_solver/advanced_solver.py` 第421-453行

**方法：** 在每个时间步后，强制右腔的所有组分保持初始值：
- Y_H2 = 0.0
- Y_O2 = 0.23
- Y_N2 = 0.77
- Y_H2O = 0.0

**原理：** 防止左腔的燃烧产物和消耗的组分通过激波混合进入右腔，同时保持质量守恒。
