# 激波管求解器 - 使用指南

## 📋 项目概述

一维激波管CFD求解器，支持H₂-O₂燃烧反应。采用HLL Riemann求解器和MUSCL-Hancock格式。

---

## 🚀 快速开始

### 方式1：无点火核（标准Sod问题）
```bash
cd shock_tube_solver
python run_clean_simulation.py
```

### 方式2：有点火核（燃烧模拟）
```bash
cd shock_tube_solver
python run_clean_simulation.py --with_ignition
```

### 方式3：查看结果
```bash
python show_results.py      # 显示数值结果
python plot_xt.py           # 绘制x-t图
```

## ⚙️ 关键参数

在 `advanced_solver.py` 中修改：

```python
# 网格和时间
nx = 1000              # 网格点数
L = 100.0              # 管长 (m)
t_end = 0.1            # 模拟时间 (s)
cfl = 0.2              # CFL数

# 燃烧反应
combustion_threshold = 800.0    # 燃烧温度阈值 (K)
reaction_rate_factor = 1.0      # 反应速率因子

# 右腔约束
enforce_no_fuel_right = True     # 强制右腔无燃料
hard_block_reaction_right = True # 硬禁用右腔反应
h2_clip_ratio = 1e-15            # 右腔H₂上限
```

## ✅ 问题解决

### 问题1：右腔燃烧
- **原因**：燃烧产物通过激波混合进入右腔
- **解决**：强制右腔组分保持初始值
- **状态**：✅ 已解决

### 问题2：膜片处氧气异常
- **原因**：消耗的O₂通过激波混合进入右腔
- **解决**：强制右腔组分保持初始值
- **状态**：✅ 已解决

## 📞 技术细节

- **空间离散**：HLL Riemann求解器 + MUSCL重构
- **时间积分**：二阶Runge-Kutta
- **边界条件**：反射边界（镜像法）
- **化学反应**：2H₂ + O₂ → 2H₂O（Arrhenius动力学）
