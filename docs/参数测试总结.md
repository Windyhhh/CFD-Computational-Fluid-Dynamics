## 理论背景

### CJ爆轰理论

CJ（Chapman-Jouguet）爆轰是一种特殊的燃烧波，具有以下特点：

1. **自持传播**：不需要外部能量输入
2. **超音速**：传播速度超过未燃气体的音速
3. **稳定结构**：前导激波 + 反应区
4. **CJ条件**：燃烧产物相对于波阵面的速度等于当地音速

### 一步反应模型的局限性

- 真实爆轰涉及数十到数百个基元反应
- 一步反应无法准确描述：
  - 诱导期（induction time）
  - 反应区结构
  - 不稳定性（胞格结构）

- 但通过参数拟合，一步反应可以：
  - 准确预测CJ速度
  - 给出合理的CJ压力和温度
  - 适用于工程计算

### 参数拟合的物理意义

- **A和Ea不是真实的化学参数**
- 它们是**有效参数**，用于匹配宏观行为（CJ速度）
- 不同的目标（火焰速度 vs CJ速度）需要不同的参数
