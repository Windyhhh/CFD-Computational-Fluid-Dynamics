**方法1：最高压力点追踪法**
```python
# 在不同时刻追踪最高压力点位置
def calculate_cj_speed(history_times, history_p_list, x_array):
    """
    计算CJ速度
    
    方法：
    1. 在每个时刻找到最高压力点位置
    2. 对位置-时间进行线性拟合
    3. 斜率即为CJ速度
    """
    shock_positions = []
    for p_snapshot in history_p_list:
        shock_idx = np.argmax(p_snapshot)
        shock_positions.append(x_array[shock_idx])
    
    # 线性拟合（只使用稳定段）
    from scipy.stats import linregress
    slope, intercept, r_value, p_value, std_err = linregress(
        history_times, shock_positions
    )
    
    cj_speed = slope  # m/s
    return cj_speed, r_value  # 返回速度和拟合优度
```

**方法2：时空图（x-t diagram）斜率法**
- 从pressure_xt.png图中提取激波前沿
- 测量斜率：CJ_speed = Δx / Δt
- 优点：可视化清晰，容易验证

### 3.4 方案D：增强验证与诊断（优先级：中⭐）

**建议1：实现CJ条件检验**

```python
def verify_cj_condition(rho, u, p, T, gamma):
    """
    验证是否满足CJ条件
    
    CJ条件：燃烧产物相对于波阵面的速度 = 当地音速
    即：u_rel = a
    
    其中：
    - u_rel = D - u（D是波速，u是流体速度）
    - a = sqrt(gamma * p / rho)
    """
    a = np.sqrt(gamma * p / rho)  # 声速
    # 在CJ点，应该有 D - u ≈ a
    # 即 u ≈ D - a
    return a
```

   - 温度测量困难（爆轰环境极端）

   - 温度可以接受较大误差（10-20%）
