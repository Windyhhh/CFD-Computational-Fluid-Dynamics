## 关于3%误差目标

### 核心结论

**简化反应模型无法达到3%误差**

这不是代码bug，而是物理模型的本质限制：

| 项目 | 简化模型（当前） | 详细机理（Cantera） |
|------|-----------------|-------------------|
| 反应数 | 1个 | 29个 |
| 组分数 | 4个 | 10个 |
| 中间产物 | 无 | OH, H, O, HO2, H2O2 |
| 反应路径 | 直接燃烧 | 链式反应 |
| 热力学 | 近似 | 精确 |

### 为什么会有误差？

1. **化学反应机理差异**
   - 简化：2H₂ + O₂ → 2H₂O（一步完成）
   - 详细：H₂ → H → OH → H₂O（多步链式反应）

2. **能量释放方式不同**
   - 简化：瞬间释放全部能量
   - 详细：逐步释放，有中间产物

3. **热力学性质计算**
   - 简化：理想气体近似
   - 详细：精确的NASA多项式
