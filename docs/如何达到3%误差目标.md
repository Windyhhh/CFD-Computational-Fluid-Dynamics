## 达到3%误差的三种方案

### 方案A：使用Cantera详细机理（推荐，精确）

**原理：**
将化学反应计算替换为Cantera，保持CFD求解器不变

**优点：**
- ✅ 精度最高（误差<3%）
- ✅ 物理真实（包含中间产物OH, H, O等）
- ✅ 无需校准参数

**缺点：**
- ⚠️ 需要重构代码
- ⚠️ 计算速度较慢（约慢10-50倍）

**实现步骤：**

1. **修改流场变量存储**
   ```python
   # 从4组分扩展到10组分（H2-O2机理）
   self.n_species = 10  # H2, H, O, O2, OH, H2O, HO2, H2O2, AR, N2
   self.Y = np.zeros((nx, 10))  # 质量分数数组
   ```

2. **使用Cantera计算热力学性质**
   ```python
   # 替换理想气体状态方程
   gas = ct.Solution('h2o2.yaml')
   gas.TPY = T[i], p[i], Y[i, :]
   rho[i] = gas.density
   e[i] = gas.int_energy_mass
   ```

3. **使用Cantera计算化学反应源项**
   ```python
   # 算子分裂法
   # 步骤1：对流步（HLLC求解器）
   # 步骤2：化学反应步（Cantera）
   reactor = ct.IdealGasConstPressureReactor(gas)
   network = ct.ReactorNet([reactor])
   network.advance(t + dt)
   ```

4. **优化计算效率**
   - 只在高温区域（T>500K）计算化学反应
   - 使用较大的化学反应时间步长
   - 使用向量化操作

**预期效果：**
- CJ压力误差：< 3%
- CJ温度误差：< 3%
- 计算时间：约5-10分钟（nx=500）

### 方案B：校准简化反应参数（快速，近似）

**原理：**

**优点：**
- ✅ 计算速度快
- ✅ 代码改动小

**缺点：**
- ⚠️ 只能在特定条件下准确
- ⚠️ 物理意义不明确
- ⚠️ 可能无法找到满足3%误差的参数

**实现方法：**

已创建校准脚本`calibrate_parameters.py`，但测试表明：
- 简单调整A和Ea无法达到3%误差

**结论：**
此方案不可行，简化模型的局限性无法通过参数调整克服

## 附录：Cantera集成示例代码

```python
import cantera as ct
import numpy as np

# 创建气体对象
gas = ct.Solution('h2o2.yaml')

# 设置初始状态
gas.TPY = 600.0, 3.0e6, {'H2': 0.15, 'O2': 0.25, 'N2': 0.60}

# 创建反应器
reactor = ct.IdealGasConstPressureReactor(gas)
network = ct.ReactorNet([reactor])

# 推进化学反应
dt = 1e-6  # 时间步长
network.advance(network.time + dt)

# 获取更新后的状态
T_new = reactor.thermo.T
p_new = reactor.thermo.P
Y_new = reactor.thermo.Y
```
