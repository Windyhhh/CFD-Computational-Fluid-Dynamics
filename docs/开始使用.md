## 🎯 快速开始

### 1️⃣ 运行无点火核模拟（标准Sod问题）

```bash
cd shock_tube_solver
python run_clean_simulation.py
```

**预期结果：**
- 右腔Y_H2O = 0.00e+00 ✓
- 右腔Y_O2 = 0.230 ✓
- 右腔无燃烧 ✓

### 2️⃣ 运行有点火核模拟（燃烧模拟）

```bash
cd shock_tube_solver
python run_clean_simulation.py --with_ignition
```

**预期结果：**
- 右腔Y_H2O = 0.00e+00 ✓
- 右腔Y_O2 = 0.230 ✓
- 右腔无燃烧 ✓
- 左腔发生燃烧 ✓

### 3️⃣ 查看结果

```bash
python show_results.py      # 显示数值结果
python plot_xt.py           # 绘制x-t图
```
