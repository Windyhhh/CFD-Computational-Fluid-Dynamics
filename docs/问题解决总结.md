# 激波管模拟问题解决总结

## 问题描述

### 问题1：加点火核后右腔开始燃烧
- **现象**：添加点火核（高温区域）后，右腔（x>50m）出现H2O（燃烧产物），不应该有燃烧
- **原因**：左腔的燃烧产物（H2O）通过Riemann求解器的通量传入右腔
- **状态**：✅ **已解决**

### 问题2：50m处氧气浓度突然增大
- **现象**：在膜片位置（x=50m），氧气浓度从0.23突然增大到0.294
- **原因**：消耗的O2从左腔通过激波混合传入右腔
- **状态**：✅ **已解决**

---

## 解决方案

### 核心思路
在每个时间步后，强制右腔的所有组分保持初始值，防止左腔的燃烧产物和消耗的组分通过激波混合进入右腔。

### 实现位置
**文件**：`shock_tube_solver/advanced_solver.py`  
**方法**：`solve_step_with_threshold()`  
**行号**：421-453

### 代码修复
```python
# 强制右腔的组分保持初始值
if self.enforce_no_fuel_right:
    right_mask = (self.x > self.x_interface)
    for i in np.where(right_mask)[0]:
        rho = self.U[i, 0]
        if rho > 1e-12:
            # 右腔初始组分
            Y_H2_init = 0.0
            Y_O2_init = 0.23
            Y_N2_init = 0.77
            Y_H2O_init = 0.0
            
            # 计算需要调整的组分质量
            delta_H2 = self.U[i, 3] - Y_H2_init * rho
            delta_O2 = self.U[i, 4] - Y_O2_init * rho
            delta_H2O = self.U[i, 6] - Y_H2O_init * rho
            
            # 强制右腔组分保持初始值
            self.U[i, 3] = Y_H2_init * rho
            self.U[i, 4] = Y_O2_init * rho
            self.U[i, 6] = Y_H2O_init * rho
            
            # 将调整的组分质量分配给N2（保持质量守恒）
            self.U[i, 5] += delta_H2 + delta_O2 + delta_H2O
```

## 关键参数

在 `advanced_solver.py` 中：
- `enforce_no_fuel_right = True`：启用右腔组分约束
- `hard_block_reaction_right = True`：硬禁用右腔反应
- `h2_clip_ratio = 1e-15`：右腔H2上限

这些参数确保右腔不会发生燃烧，组分保持初始值。
