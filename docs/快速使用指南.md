## ⚙️ 参数调整

### 网格点数
```bash
# 默认1000点
python shock_tube_solver/run_clean_simulation.py --with_ignition --nx 1000

# 高精度2000点
python shock_tube_solver/run_clean_simulation.py --with_ignition --nx 2000

# 快速测试500点
python shock_tube_solver/run_clean_simulation.py --with_ignition --nx 500
```

### CFL数（时间步长）
```bash
# 默认CFL=0.2
python shock_tube_solver/run_clean_simulation.py --with_ignition --cfl 0.2

# 更稳定（更慢）
python shock_tube_solver/run_clean_simulation.py --with_ignition --cfl 0.1

# 更快（可能不稳定）
python shock_tube_solver/run_clean_simulation.py --with_ignition --cfl 0.3
```

### 模拟时间
```bash
# 默认0.01秒
python shock_tube_solver/run_clean_simulation.py --with_ignition --t_end 0.01

# 更长时间
python shock_tube_solver/run_clean_simulation.py --with_ignition --t_end 0.02
```

### 燃烧阈值
```bash
# 默认800K
python shock_tube_solver/run_clean_simulation.py --with_ignition --combustion_threshold 800

# 更高阈值（更难点火）
python shock_tube_solver/run_clean_simulation.py --with_ignition --combustion_threshold 1000

# 更低阈值（更容易点火）
python shock_tube_solver/run_clean_simulation.py --with_ignition --combustion_threshold 600
```

## 🔧 常见问题

### Q1: 如何调整网格点数？
```bash
python shock_tube_solver/run_clean_simulation.py --with_ignition --nx 2000
```

### Q2: 模拟太慢怎么办？
- 减少网格点数：`--nx 500`
- 增大CFL数：`--cfl 0.3`
- 减少模拟时间：`--t_end 0.005`

### Q3: 结果不稳定怎么办？
- 增加网格点数：`--nx 2000`
- 减小CFL数：`--cfl 0.1`
- 降低燃烧阈值：`--combustion_threshold 700`

### Q4: 如何查看详细输出？
查看`results/`目录中的文件：
```bash
# Windows
explorer results

# 或者用Python读取
python
>>> import numpy as np
>>> data = np.loadtxt('results/advanced_final_t_0.010002.txt', delimiter=',', skiprows=1)
>>> x = data[:, 0]
>>> p = data[:, 3]
```

### Q5: 如何与理论解对比？
```bash
python shock_tube_solver/compare_with_cantera.py
```
