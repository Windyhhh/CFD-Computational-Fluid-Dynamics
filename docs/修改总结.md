## 修改原理

### 问题根源
在Riemann求解器中，组分通量使用上风格式计算：
- 当流向右侧时，使用左侧单元的组分
- 这导致左腔的组分（包括燃烧产物）进入右腔

### 解决方案
在右腔的界面处，强制使用右腔的初始组分，而不是左腔的组分。这样可以：
1. 防止左腔组分进入右腔
2. 保持右腔组分稳定
3. 消除数值振荡

## 验证

✅ **所有测试通过**：
- 有点火核：Y_O2 振荡幅度 0.29% < 1%
- 无点火核：Y_O2 振荡幅度 0.16% < 1%
- 右腔无燃烧：Y_H2O = 0.00e+00
